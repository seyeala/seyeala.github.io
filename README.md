# Seyedhamidreza Alaie — Personal Academic Website

Source for the GitHub Pages site at `seyeala.github.io`.

The site is a static HTML/CSS academic website. The canonical homepage is `index.html`. Legacy entry points such as `about.html`, `ml.html`, and `News.html` redirect to their current locations.

## Structure

- `index.html` — homepage and contact/profile information
- `research.html` — research overview and repositories
- `laboratory.html` — laboratory capabilities
- `publications.html` — selected publications, including machine-learning work
- `team.html` — research group members
- `service.html` — professional service
- `opportunities.html` — student opportunities
- `calendar.html` — public events calendar
- `outreach.html` — outreach
- `news.html` — news
- `CV.pdf` — curriculum vitae
- `style.css` — shared responsive site styling

## Repository maintenance

The TensorFlow.js webcam demo that previously occupied the root landing page is preserved in Git history and in `archive/pre-housekeeping-2026-09-26`. Its runtime files are intentionally excluded from the active site branch.
